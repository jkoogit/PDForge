# PDForge

PDForge는 pdfrend와 분리된 독립 제품으로 PDF 뷰어/문서 경험 서비스를 만들기 위한 준비 저장소입니다.

이 저장소의 초기 목표는 곧바로 코딩을 시작하는 것이 아니라, AI 주도 개발 방식과 에이전트 협업 구조를 먼저 학습하고 운영 기준을 정리한 뒤 제품 개발을 시작하는 것입니다.

## 현재 단계

- 제품 구현 전 준비 단계
- 문서 기반 정책, 기획, 설계, 하네스 학습 단계
- GitHub Copilot, Codex 등 AI 에이전트를 활용한 개발 운영 방식 정리 단계
