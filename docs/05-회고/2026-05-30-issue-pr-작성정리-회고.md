# 2026-05-30 Issue와 PR 작성 정리 회고

## 작업 내용

- PR 작성 내용에 관련 Issue를 포함하도록 PR 템플릿을 보완했습니다.
- GitHub 운영 프로세스에 Issue와 PR 연결 규칙을 추가했습니다.
- Issue와 PR 작성 가이드를 새 문서로 추가했습니다.
- 아직 실제 GitHub Issue 번호가 없을 때 PR에 임시 Issue 요약을 포함하는 방식을 정리했습니다.

## 잘된 점

- 에이전트가 PR을 만들 때 어떤 Issue를 해결하는지 먼저 적도록 기준이 명확해졌습니다.
- 실제 Issue 번호가 없는 초기 문서 작업도 배경, 목표, 완료 조건, 제외 범위로 추적할 수 있게 되었습니다.
- 앞으로 PR 리뷰에서 “이 작업이 어떤 요청을 해결하는가?”를 더 쉽게 확인할 수 있습니다.

## 어려웠던 점

- 현재 저장소 작업은 실제 GitHub Issue 번호가 없는 상태에서 진행되었기 때문에 `Closes #번호`를 바로 확정할 수 없습니다.
- 따라서 이번 문서에서는 실제 번호 대신 임시 Issue 요약을 PR 본문에 포함하는 운영 방식을 함께 정리했습니다.

## 다음 개선점

- 다음 작업부터는 먼저 GitHub Issue를 만들고 Issue 번호를 PR 본문에 연결합니다.
- 기존 문서 작업도 필요하면 GitHub Issue를 역으로 만들어 PR과 연결합니다.
- 에이전트 작업 요청 프롬프트에 “관련 Issue를 PR 본문 맨 위에 적기”를 포함합니다.
