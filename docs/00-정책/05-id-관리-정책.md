## Issue ID 규칙

Issue 문서 ID는 작업 ID와 순번을 조합합니다.

```text
ISSUE-{작업ID}-{순번}
```

예시:

```text
ISSUE-TASK-MVP-001-1
ISSUE-TASK-MVP-001-2
```

GitHub Issue 번호는 생성 전까지 비워둡니다.

## PR ID 규칙

PR 문서 ID는 Issue 문서 ID와 PR 순번을 조합합니다.

```text
PR-{Issue문서ID}-{순번}
```

예시:

```text
PR-ISSUE-TASK-MVP-001-1-1
```

GitHub PR 번호는 생성 전까지 비워둡니다.
