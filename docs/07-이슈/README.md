# Issue 문서 관리

## 문서 ID

- 정책 ID: `POL-ISSUE-001`
- 관련 작업 ID: `TASK-MVP-001`

## 목적

GitHub Issue에 작성할 내용을 문서로 먼저 관리합니다. 실제 GitHub Issue 번호가 생기기 전까지는 번호 자리를 비워두고, 생성 후 문서를 현행화합니다.

## 파일명 규칙

```text
[이슈번호](작업ID-순번)_배경_작업내용.md
```

예시:

```text
[](TASK-MVP-001-1)_초기정책_문서정리.md
[12](TASK-MVP-001-1)_초기정책_문서정리.md
```
