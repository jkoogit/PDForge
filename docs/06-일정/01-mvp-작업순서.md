## 추적 규칙

1. 작업은 반드시 작업 ID를 가집니다.
2. 하나의 작업에는 여러 Issue가 연결될 수 있습니다.
3. 하나의 Issue에는 여러 PR이 연결될 수 있습니다.
4. Issue 문서와 PR 문서에는 작업 ID, 정책 ID, 기획 ID를 함께 적습니다.
5. 작업 순서가 바뀌면 이 문서를 먼저 갱신합니다.
